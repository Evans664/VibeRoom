# Ice

## Role
Frontend and visual implementation owner.

## Responsibilities
- UI and CSS implementation
- Responsive layouts and reusable components
- Visual consistency with the VibeRoom design system
- Accessibility and interaction states

## Likely files
`css/`, `pages/`, `js/ui/`, and page-facing parts of `js/core/`.

## Integration expectations
Render contract-shaped data and mock data first. Keep Firebase calls out of UI files. Preserve mobile-first behavior, keyboard access, focus visibility, and loading/empty/error states.

Contributors may help with backend work when assigned; ownership describes coordination, not a restriction.
